## 🎃 Halloween - Desafio 1

Oi, eu sou o Igor e este é o espaço onde compartilho minha jornada de aprendizado durante o desafio **Halloween 2026**, realizado pelo [balta.io](https://balta.io). 👻

Aqui você vai encontrar projetos, exercícios e códigos que estou desenvolvendo durante o desafio.

### Sobre este desafio
Neste desafio o objetivo é consolidar os fundamentos do Spec Driven Development, criando uma constituição, especificação, planejamento e tarefas manualmente para serem implementadas pela IA posteriormente.

#### O que foi implementado
- Foi implementada uma API simples, com dois endpoints, sendo um que gera senhas fortes seguindo um padrão e outro que dado um GUID, permite consultar uma senha associada, utilizando IA.

Neste processo eu aprendi:
* ✅ Criar os arquivos de constituição, especificação, plano técnico e tarefas, para desenvolver um projeto de uma API utilizando SDD (Spec-Driven Development)
